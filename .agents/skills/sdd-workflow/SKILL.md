# SDD Workflow Skill — ManoCerca

## 1. Fases Obligatorias para Funcionalidades Complex (> 2 archivos)
1. **Explore**: Leer prototipo Figma y documentos `docs/contexto/`.
2. **Propose**: Planificar la estructura HTML, Tailwind y JS.
3. **Tasks**: Dividir el trabajo en tareas atómicas.
4. **Apply**: Escribir código limpio sin logs de depuración sobrantes.
5. **Verify**: Probar responsiveness, 5 estados UI y accesibilidad WCAG AA.

## 2. Fast-Path
- Para correcciones simples o cambios limitados a 1 archivo, aplicar directamente previa inspección y verificación.
