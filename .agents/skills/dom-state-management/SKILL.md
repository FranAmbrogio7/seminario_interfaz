# DOM & State Management Skill — ManoCerca

## 1. Patrón SPA en JavaScript Vanilla
- Alternar vistas dinámicamente según el rol seleccionado (Cliente vs Prestador).
- Renderizado reactivo de tarjetas mediante plantillas HTML / template literals de JS.

## 2. Persistencia Local
- Guardar solicitudes, propuestas y estado de chat en `localStorage` o `IndexedDB` para mantener el estado entre recargas.

## 3. Feedback Visual de Interacción
- Validación en tiempo real de formularios (`input`, `change`).
- Notificaciones de éxito/error mediante modales o componentes Toast flotantes.
