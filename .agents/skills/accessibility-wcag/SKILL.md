# Accessibility & WCAG AA Skill — ManoCerca

## 1. Reglas Fundamentales
- **Contraste Mínimo**: $\ge 4.5:1$ en texto normal, $\ge 3:1$ en elementos gráficos.
- **Área Táctil Mínima**: $44\text{px} \times 44\text{px}$ en botones e inputs móviles.
- **Navegación por Teclado**: Todos los elementos clickeables deben responder a `Tab`, `Enter` y `Espacio`.

## 2. Elementos Semánticos
- Usar siempre `<button>` para acciones y `<a>` para navegación.
- Incluir atributo `alt` descriptivo en todas las imágenes de prestadores y trabajos.
- Formular etiquetas `<label for="...">` asociadas a cada `<input>`.
