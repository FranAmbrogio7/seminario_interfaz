# Glosario y Rotulado del Dominio (ManoCerca)

## 1. Reglas de Negocio Nucleares
1. **Identidad Verificada**: Todo prestador que haya validado su documentación debe exhibir el badge visual `✓ Identidad verificada`.
2. **Ciclo de Estado del Trabajo**: Las solicitudes transitan únicamente por los estados: `Publicado` ➔ `En negociación` ➔ `Aceptado` ➔ `En curso` ➔ `Finalizado`.
3. **Calificaciones Habilitadas**: El cliente solo puede emitir calificación y reseña una vez que el trabajo está en estado `Finalizado`.
4. **Privacidad de Dirección**: La ubicación del cliente se muestra como zona aproximada (ej: `📍 Bariloche, a 2.4 km`) hasta que el servicio sea aceptado.

## 2. Tabla de Rotulado Orientado al Usuario (Labeling vs Dev Jargon)

| Concepto Técnico (Dev Jargon) | Etiqueta en Interfaz (Lenguaje Natural) | Descripción |
| :--- | :--- | :--- |
| `User` | **Usuario** | Persona registrada en la plataforma. |
| `Provider` | **Prestador** | Trabajador o profesional de servicios del hogar. |
| `Job Request` | **Solicitud de trabajo** | Publicación del problema que requiere solución. |
| `Service` | **Servicio** | Categoría u oficio (Plomería, Gas, Electricidad). |
| `Proposal` | **Propuesta** | Oferta enviada por un prestador. |
| `Quote` | **Presupuesto** | Estimación económica enviada en la propuesta. |
| `Chat` | **Mensajes** | Canal de comunicación directo entre partes. |
| `Rating` | **Calificación** | Puntuación con estrellas ($\star 1$ a $\star 5$). |
| `Review` | **Reseña** | Opinión escrita sobre el servicio realizado. |
| `Job History` | **Historial** | Registro de trabajos pasados. |
| `Verification` | **Identidad verificada** | Badge de confianza del prestador. |
| `Report` | **Denunciar** | Alerta sobre publicaciones o conductas indebidas. |
| `Dashboard` | **Inicio** | Pantalla principal de la SPA. |
| `Status` | **Estado del trabajo** | Etapa actual en el ciclo de vida. |
